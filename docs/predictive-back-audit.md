# Predictive Back & Navigation Audit (`fix/predictive-back-audit`)

> Generated in Step 0 from static source inspection across `app/src/main/java/com/petal/browser/` and `app/src/main/AndroidManifest.xml`.

## Defect Key
- **A**: Nested Settings categories (`parentCategory != null`) disable `PetalPredictiveBackSurface`, register a plain `BackHandler`, and swap via `PetalSettingsAnimatedContent` (no preview, no blur, crossfade ghosting).
- **B**: `ScannerHost` uses early-`return` branches for `PetalScannerSettingsScreen` and `PetalScannerHistoryScreen` that tear down the camera preview, register inner `PetalPredictiveBackSurface` without `PetalScreenWrapper`, and omit `PetalScreenWrapper` on the scanner root.
- **C**: `SafeLockerScreen` inside `PetalRootApp` (`~L1768`) does not receive `backgroundSnapshot` (`overlayPageSnapshot ?: tabSwitcherSnapshot`).
- **D**: `PetalRootApp` skips snapshot capture when depth blur is OFF (`wantsPageSnapshot` requires `predictiveBlurEnabled`), and `hasLiveUnderlay()` chooses the live underlay path over a SurfaceView-backed GeckoView page when blur is off (or over web pages without TextureView), so blur-off previews behind overlays fail/blank out.
- **E**: Shutter / flash on committed predictive back return:
  1. `PetalPredictiveBackSurface` holds `dismissed = true` for `HOLD_DISMISSED_MS = 500L` while `AnimatedVisibility` runs its own exit (`PetalSpring.calm`), then resets to `Idle` -> screen can flash back on screen if exit outlasts 500ms.
  2. `dismissed = true` immediately hides `Layer 0` (`!predictiveBackState.dismissed`) and sets top alpha `0f` simultaneously while resetting `liveBehind = null` at `onGestureEnd(true)`, snapping the page from blurred/dimmed pose to sharp.
  3. Overlays in `PetalRootApp` run their `AnimatedVisibility` exit (`fadeOut + slideOutVertically`) even after a committed gesture already animated dismissal.
  4. `PetalBackMotion.aospBounce()` / settled `frame(1)` behavior should settle cleanly at identity.
- **F** *(new)*: `PrivacySettingsScreen` (`~L214-223`) renders `PetalAdBlockSettingsScreen` via an early-`return` branch with no `BackHandler`, no `PetalPredictiveBackSurface`, and no `PetalSubPageHost` (system back pops all of `Privacy`, not `AdBlock` settings).
- **G** *(new)*: `PetalFilePickerBridge` (`~L176-178`) calls `clearContentFrameKeepingTabs()` without `PetalContentSnapshot.capture(rootView)` and `PetalFilePickerScreen` (`L234`) calls `PetalScreenWrapper {}` without `backgroundSnapshot` (`FilePicker` root in `MainActivity` has empty behind preview).
- **H** *(new)*: `PetalPasswordsActivity` (`L30`) hosts `PetalPasswordsScreen(embedded = false)`, which invokes `PetalPredictiveShell(wrap = true)` and intercepts leaving the Activity instead of letting the AOSP system cross-activity back animation run (no in-app backdrop behind a standalone Activity).
- **I** *(new)*: `PetalScannerActivity` (`L25`) hosts `ScannerHost`, whose root `PetalPredictiveBackSurface` (`L341`) is enabled when no sub-page/sheet is open, intercepting system cross-activity back when leaving `PetalScannerActivity`.
