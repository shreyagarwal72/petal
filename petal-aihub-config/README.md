# Petal AI Hub — Self-Hosted Cloud Configuration Repository

This repository contains the official self-hosted dataset and static web portal for **Petal Browser AI Hub**.

## 🚀 Files Included

- **`ais.json`**: Real-time AI tools database with categorization, pricing model, privacy ratings, login requirements, and "best-for" tags.
- **`domains.txt`**: Domain mappings list for AI services.
- **`index.html`**: Premium, modern interactive web portal featuring glassmorphism design, live search, category filtering, and direct launcher cards.

## 🌐 Host on GitHub Pages (100% Free & Fully Owned)

1. Create a new GitHub repository named `petal-aihub-config`.
2. Push the files in this directory to your repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of self-hosted AI Hub config"
   git remote add origin https://github.com/shreyagarwal72/petal-aihub-config.git
   git push -u origin main
   ```
3. Go to **Repository Settings** -> **Pages** -> Select **Source: main branch** -> **Save**.
4. Your self-hosted AI Hub endpoint will be live at:
   `https://shreyagarwal72.github.io/petal-aihub-config/`

## 📱 Embedded in Petal Browser

Petal Browser dynamically syncs with this repository to update AI services in real time without requiring app updates.
