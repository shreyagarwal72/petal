## Information Collection And Use

Petal Browser software requires certain functionalities and permissions to be enabled to ensure smooth operation when its services are utilized, however, none of these technicalities explicitly allow or give the developer access to your personal or private information.

For the software to function efficiently the following permissions are required:

- location (disabled by default)
- camera (WebRTC / barcode scanner support)
- microphone (WebRTC support: for example audio conferences)
- storage (to make and restore backups and download files)
- sensors (detect screen orientation/UI mode)
- internet access (web browser navigation)

These permissions can be disabled if you don't require the service they provide. <hr>

## About

Petal Browser is an open-source browser developed for Android, combining the standalone Mozilla GeckoView engine with Material 3 Expressive design.

Some features of Petal Browser include:

- Mozilla GeckoView rendering with Firefox WebExtensions (AMO) support
- Total Cookie Protection and Enhanced Tracking Protection
- Material 3 Expressive UI, Dynamic Theming & Living Backgrounds
- Dedicated built-in extensions (Dark Webpages, Clean Link, Universal Copy, AI Blocker)
- Material 3 Expressive Find in Page
- Resumable download manager with live dynamic status notifications
- Native picture-in-picture video player with expressive gestures
