Why Petal

Not another Chromium wrapper.

Most Android browsers sit on top of the system WebView. Petal ships Mozilla's own engine and the Firefox component stack instead.

Mozilla's engine, bundled

GeckoView 159 with Mozilla Android Components 159.0.1. Rendering, WebExtensions, Total Cookie Protection and the download service all come from Mozilla's code, so they update when Firefox does.

  • GeckoView 159
  • Firefox add-ons
  • Total Cookie Protection

Blocking that runs first

A bundled WebExtension cancels ad and tracker requests before they leave the device, using EasyList, uBlock uAssets and Hagezi lists. Strict tracking protection is on from the first launch, and there is no Firebase or analytics SDK.

  • petal_network_blocker
  • Strict ETP
  • HTTPS-only option

Material 3 Expressive in the details

Jetpack Compose with Material 3 1.5, 35 expressive shapes, spring motion, predictive back, dynamic colour and a true-black AMOLED theme. Most of the settings you see on this page are the real app settings.

  • Dynamic colour
  • AMOLED black

In the app today

What you get in 4.8

A short list of what is shipping in the current release. The changelog has the rest.

  • Workspaces, folders and pinned tabs

    Group tabs into workspaces, collapse them into folders, pin essentials, and peek at a link in a Glance sheet without leaving the page.

  • A proper add-on manager

    Installed, Explore and Tweaks tabs, a permissions inspector, per-add-on private-window control, and .xpi import. Ten small built-in add-ons ship with the app.

  • One Privacy & Security page

    Ad and tracker blocking, tracking protection, fingerprinting, connection security (HTTPS-only, DNS-over-HTTPS, WebRTC leak shield), site permissions, private browsing and passwords.

  • Downloads on Mozilla's service

    Browser downloads go through Mozilla's download service, so cookies, logins and private mode carry over. Files you delete are removed from storage.

  • Firefox Account sync

    Sign in with a Firefox Account to sync bookmarks, history, passwords and open tabs, and to send a tab to any device you own.

  • Media, reader and AI

    Video and audio player with picture-in-picture, a reader mode with read-aloud, and an optional AI assistant that uses your own API key.

Petal is translated into 28 languages. The GitHub and Google Play builds include one opt-in rewarded ad to support development; the F-Droid build has no ad code.

How it works

What sits under the interface

Petal is one Kotlin app. Mozilla's engine renders pages, Mozilla's components manage tabs and downloads, and Compose draws everything you touch.

Engine

GeckoView 159 with Mozilla Android Components

Petal embeds GeckoView 159.0 and Mozilla Android Components 159.0.1. One active tab is mounted at a time and background tabs live in Mozilla's BrowserStore, which keeps GPU memory low. The system WebView is not used.

implementation 'org.mozilla.geckoview:geckoview:159.0.20261102144711'
implementation 'org.mozilla.components:browser-engine-gecko:159.0.1'
implementation 'org.mozilla.components:browser-state:159.0.1'

Versions and tooling

Read straight from the project's build files.

  • Release

    v4.8.0
    Full notes on the changelog page.

  • Browser engine

    Mozilla GeckoView 159.0
    With Mozilla Android Components 159.0.1 for tabs, downloads, sync and prompts.

  • Language

    100% Kotlin 2.4
    About 660 Kotlin source files, no Java. JVM 17 target, built with Android Gradle Plugin 9.4, KSP and Hilt.

    Expressive APIs such as shape morphing, springs and the new button groups.

    Android 8.0 (API 26) to API 36
    Compile and target SDK 36.

  • CPU architectures

    arm64-v8a armeabi-v7a x86 x86_64
    A universal APK plus per-ABI builds.

  • Ad & tracker blocking

    EasyList, uBlock uAssets and Hagezi lists. Licences are in open-source licences.
