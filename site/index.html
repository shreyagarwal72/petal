Engineered to be the anti-Chromium.

Most Android browsers are repackaged Chromium shells bundled with tracking services. Petal is an independent, native engineering achievement.

GeckoView 157 quantum pipeline

Petal does not delegate web rendering to the manufacturer's Android WebView. It bundles Mozilla's quantum engine with full multi-process isolation, native Firefox add-ons, and standards compliance.

  • Standalone engine
  • Firefox Add-ons (AMO)
  • Quantum multi-process

Zero telemetry by construction

Privacy is not a toggle in a submenu. Petal bundles zero analytics SDKs, zero telemetry endpoints, and zero cloud reporting beacons. Strict Enhanced Tracking Protection is active on first launch.

  • No Google Firebase
  • No Sentry
  • Isolated cookie jars

Independent Quantum Core

GeckoView 157 Standalone Engine

Petal embeds Mozilla GeckoView 157 with an isolated quantum multi-process pipeline. It does not use the OEM Android WebView, preventing vendor delays and third-party tracking hooks.

GeckoRuntime.create(context, GeckoRuntimeSettings.Builder()
  .aboutConfigEnabled(true)
  .contentBlocking(ContentBlocking.STRICT)
  .build())

Complete technical stack

Verified details from the codebase, kept apart from marketing assumptions.

  • Browsing engine

    Mozilla GeckoView 157.0.0
    Desktop-grade standards compliance, independent of Chromium WebView.

  • Language & toolchain

    Kotlin 2.0+, Java 17, Gradle 8.x
    Type-safe coroutines, Flow-based state, and null safety throughout.

  • UI framework

    Jetpack Compose + Material 3 Expressive 1.5.0-alpha17
    Spring animations, adaptive polygon morphing, fluid 120Hz gesture handling.

  • Target architectures

    arm64-v8a armeabi-v7a x86 x86_64
    Universal APK and ABI-split builds for legacy and modern Android devices.

  • Operating system range

    Android 8.0 (API 26) through Android 15/16 (API 36)
    Broad compatibility with backward-compatible Room database migrations.

  • Haptic feedback

    Custom PetalHapticEngine
    Synthesizes tactile waveform ticks on scroll, swipe, and seekbar thresholds.

  • Authentication

    FIDO2 / Passkey hardware bridge
    Passwordless biometric login directly compatible with WebAuthn specs.

  • License

    GNU General Public License v3.0 (GPL-3.0)
    100% open-source software ensuring complete auditability and user freedom.
