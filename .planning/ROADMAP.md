# Roadmap: Petal Motion Architecture

### Milestone 1: Core Motion Overhaul

- [x] **Phase 01: Motion Foundation**
  - Goal: PetalSpring tokens, MotionGate counter-based gating, snapshot policy, JankStats.
  - Status: Complete.

- [x] **Phase 02: Tab Transitions**
  - Goal: Button-origin new tab morph, card shrink/fade close, category horizontal slide with fade-through, interruptible hero.
  - Status: Complete.

- [x] **Phase 03: Address Bar and Page Chrome**
  - Goal: Address bar <-> Omnibox container morph, scroll-to-pill directly driven by scroll offset, progress & favicon synchronized fade, omnibox suggestions list-reorder.
  - Status: Complete.

- [x] **Phase 04: Menus, Sheets, Settings and Audit**
  - Goal: Origin-anchored menus, velocity-settled bottom sheets, settings & downloads container morphs, shared dialog pop-in/exit, inline animation audit, motion documentation.
  - Status: Complete.

- [x] **Phase 05: Web-Facing GeckoView and Permissions Fixes**
  - Goal: Real error pages via browser-errorpages, activity runtime permission bridges, autoplay/storage/XR content permissions, prompt hang fixes and CCT/PWA file upload support.
  - Status: Complete.
