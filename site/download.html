Requirements

  • Android 8.0 (API 26) or newer.
  • A device with enough free storage for the app and the GeckoView engine.

Install from GitHub

  1. Open the latest release and download the APK file from the Assets list.
  2. Open the downloaded file. If Android blocks it, tap Settings and allow installs from the browser or file manager you used.
  3. Tap Install, then open Petal.
  4. Optional: set Petal as your default browser in Android Settings, Apps, Default apps.

Updating

Builds installed from GitHub can check for new releases inside the app. You can also download the newest APK and install it over your current version; your data is kept because the signing key stays the same.

Other channels

Petal is distributed through GitHub releases. Other stores will be listed here when they are available. Always download from the official repository or links on this website.

Stay safe

  • Only install Petal from this website or the official GitHub repository.
  • Read the Privacy Policy and Terms of Use.
  • Need help? See the FAQ or Support.
