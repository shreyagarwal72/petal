# Predictive Back & Navigation Audit (`fix/predictive-back-audit`)

> Audited across `app/src/main/java/com/petal/browser/` and `app/src/main/AndroidManifest.xml` on branch `fix/predictive-back-audit`.
> Updated in Step 5 after applying fixes across Steps 1–4 and running static verification.

## Defect Key (All Resolved)
- **A** *(Fixed — Step 2)*: Nested Settings categories (`parentCategory != null`) in `compose/settings/PetalSettingsScreen.kt` now render through `PetalSubPageHost` (live parent preserved & blurred behind) instead of disabling `PetalPredictiveBackSurface`, registering a plain `BackHandler`, and swapping via `PetalSettingsAnimatedContent`.
- **B** *(Fixed — Step 3)*: `scanner/ScannerHost.kt` no longer uses early-`return` branches for `PetalScannerSettingsScreen` and `PetalScannerHistoryScreen`; both run inside `PetalSubPageHost` over the live camera `PreviewView` parent with inner `PetalPredictiveBackSurface` removed from `PetalScannerSettingsScreen` and `PetalScannerHistoryScreen`.
- **C** *(Fixed — Steps 1 & 4)*: `SafeLockerScreen` in `compose/PetalRootApp.kt` is no longer excluded from `liveEligible`/`wantsPageSnapshot` and now receives `backgroundSnapshot = overlayPageSnapshot ?: tabSwitcherSnapshot`.
- **D** *(Fixed — Step 1)*: `compose/PetalRootApp.kt` now captures `wantsPageSnapshot` regardless of `isDepthBlurEnabled` whenever `junctionPredictiveEnabled` holds over a non-home page, and `hasLiveUnderlay()` uses the frozen snapshot (`liveEligible && (isHomeState || liveBlurCapable() || overlayPageSnapshotState == null)`) over SurfaceView-backed GeckoView pages.
- **E** *(Fixed — Step 1)*: Eliminated shutter/flash on committed predictive back:
  1. `predictive/PetalBackStyle.kt`: `aospBounce(i)` returns `1f` at `settleTime >= 1f` and tapers `overlay` linearly over `0.85f..1f`.
  2. `predictive/PetalPredictiveJunction.kt`: replaced fixed `HOLD_DISMISSED_MS = 500L` delay with `DisposableEffect.onDispose` `CompletableDeferred` handoff (bounded by `DISMISS_SAFETY_CAP_MS = 650L`) so `PetalLiveUnderlay.end(true)` only runs once the overlay leaves composition (`activeLiveUnderlay` guarded).
  3. `predictive/PetalPredictiveJunction.kt`: `PetalScreenWrapper` Layer 0 stays visible at settled pose during `dismissed` and dissolves smoothly over `SNAPSHOT_DISSOLVE_MS = 90` ms instead of snapping off immediately.
  4. `compose/PetalRootApp.kt`: overlays use `overlayExit` (`ExitTransition.None` when `PetalPredictiveJunction.gestureDismissed` is true, cleared via `LaunchedEffect` on next open) so `AnimatedVisibility` does not replay slide/fade exit animations.
- **F** *(Fixed — Step 4)*: `compose/settings/screens/PrivacySettingsScreen.kt` replaced its early-`return` `showAdBlockSettings` (`PetalAdBlockSettingsScreen`) branch with `PetalSubPageHost` unified alongside `showPasswordsScreen`.
- **G** *(Fixed — Step 4)*: `compose/file/PetalFilePickerBridge.kt` & `PetalFilePickerScreen.kt` now pass `backgroundSnapshot` captured via `PetalContentSnapshot` (via `captureBrowserMainPreview()` or `decorView.rootView` before dialog presentation) into `PetalScreenWrapper(backgroundSnapshot = backgroundSnapshot)`.
- **H** *(Fixed — Step 4)*: `passwords/PetalPasswordsActivity.kt` passes `isStandaloneActivity = true` to `PetalPasswordsScreen`, disabling the outer `PetalPredictiveShell` while keeping internal `hasSubOverlay` `BackHandler` intact so Android handles cross-activity exit.
- **I** *(Fixed — Step 3)*: `lens/PetalScannerActivity.kt` passes `wrapPredictive = false` to `ScannerHost`, letting Android handle cross-activity exit while keeping `PetalSubPageHost` active for in-scanner Settings and History.
