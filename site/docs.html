Overview

Petal is a private, open-source Android browser built on Mozilla's GeckoView engine rather than the system WebView, with a Jetpack Compose interface designed in Material 3 Expressive. This page is the quick user guide; the FAQ covers troubleshooting and the architecture page covers internals.

Getting started

  1. Install. Get Petal from Google Play or download the signed APK from GitHub Releases. Petal needs Android 8.0 or newer.
  2. Open and browse. There is no account to create. Type or paste an address, or search straight from the address bar.
  3. Make it yours. Open Settings to pick a palette, theme and layout (see Customize).
The GitHub build updates itself from GitHub Releases; the Play build updates through Google Play.

Browsing

  • Floating pill bar. The tab and navigation bar can float as a pill. Toggle it in the layout settings.
  • Back gestures. Predictive back shows the previous page while you swipe.
  • Optional AI search. Bring your own key (Gemini, OpenAI, Anthropic, Groq) or point Petal at a local Ollama server. Nothing is sent unless you set a key.

Privacy & security

  • Ad and tracker blocking runs in a native Rust engine with uBlock and Hagezi lists, before content loads.
  • Per-site shield lets you tune tracking protection for each website.
  • Password vault is stored locally, encrypted, and unlocked with biometrics.
  • No telemetry and no accounts.

Petal asks for permissions only when you use the related feature:

PermissionWhy
CAMERA, RECORD_AUDIOOnly when a page or the QR scanner asks.
ACCESS_FINE_LOCATIONOptional, prompted per site.
USE_BIOMETRICUnlock the password vault.
ACCESS_NETWORK_STATEDetect connection state.

Add-ons

Because Petal runs on Gecko, it supports Firefox WebExtensions. Open the extensions screen from the menu to install and manage add-ons.

Downloads & media

  • A multi-threaded download manager keeps going in the background.
  • Video can continue in a floating picture-in-picture player.
  • PDFs open in the built-in viewer.

Customize

  • Dynamic color follows your wallpaper on Android 12 and newer; older devices use the Petal palette.
  • Dark, light and true-black AMOLED themes.
  • Expressive shapes and motion use spring physics and morphing shapes throughout the app. Haptics follow your system touch-feedback setting.

Petal Hop (offline game)

When a page can't load because of the connection, Petal can show a small endless-runner instead of a dead end. Tap to hop over clouds, thorns and bees; hold for a higher jump. A host-not-found error waits for you to press Play while you wait, since that is often a typo. When the connection returns, a pill offers to reload the page.

Turn it off any time in Settings → Misc → Offline game to see the normal error page.

Build from source

Petal is GPL-3.0 and lives at github.com/shreyagarwal72/petal. It uses Gradle product flavors (github, play, fdroid). See the README's build section and architecture before opening a pull request; community rules apply.
